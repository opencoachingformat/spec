Handball

Reserved

The shared OCF structure — court, entities, frames — already fits this sport. Its action vocabulary is provisional and open for contribution.

Action types

  • move
  • pass
  • shoot
  • defend
  • cut
  • screen
  • pickup

Contribute

Handball is reserved: the format is ready, but its action vocabulary needs the people who know the game. If you coach or play handball, you can help define the actions, variants, outcomes, and rulesets that make an OCF handballplay precise.

  • Sport experts wanted. Propose the action vocabulary for Handball through the RFC process — no code required to start the conversation.
  • Open an RFC or discussion. See the RFC process in the specification repository.
  • Browse the repository. The opencoachingformat/spec repo holds the sport registry files under sports/.
